# Installation

## Stable release

To install RainfallGridder, run this command in your terminal:

```sh
uv add rainfall-gridder
```

Or if you prefer to use `pip`:

```sh
pip install rainfall-gridder
```

## From source

The source files for RainfallGridder can be downloaded from the [Codeberg repo](https://github.com/thomasjkeel/rainfall_gridder).

You can either clone the public repository:

```sh
git clone https://codeberg.org/thomasjkeel/RainfallGridder
```

Or download the [tarball](https://codeberg.org/thomasjkeel/rainfall_gridder/tarball/main):

```sh
curl -OJL https://codeberg.org/thomasjkeel/RainfallGridder/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd RainfallGridder
uv sync
```
